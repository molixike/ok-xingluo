# OK影视·星落融合版 安装说明

成品：OK影视-星落融合版.apk（82,211,508 字节，包名 com.fongmi.android.tv，版本 5.1.6 不变）
原包未做任何删改，仅多了 3 个内置文件和 1 处种子补丁（见下）。

## 装之前必看

1. **签名换了**：这个包用新证书（Xingluo Merge）签名，和你手机上现在那个 OK（OKTV Merge 证书）签名不一致，
   **不能覆盖安装**。先在现在的 OK 里用它自带的备份功能把配置/历史备份好，再卸载旧版、装这个新版，最后恢复备份。
2. 签名证书文件 `xingluo-merge.keystore` 一并给你了（密码：xingluo2026，别名 xingluo）。
   以后这个融合版要再出新版，必须用这把钥匙签名才能覆盖升级，收好别丢。
3. 本包在打包机上通过了：重新编译、签名校验（v1/v2/v3）、包结构与原版逐项比对（权限/页面/dex 数量一致，只多了 3 个文件）。
   打包环境没有安卓真机/模拟器，**实际运行请你装上后验一遍**，有闪退把现象告诉我，我按补丁位置继续修。

## 内置了什么、怎么生效

- **1118.jar（星落爬虫包）**：已放进包内 assets。APP 首次启动、且你还没填任何接口时，
  会自动把内置配置设为默认接口（配置名"星落内置"），它的 spider 指向包内 jar（assets:// 机制，基座原生支持），
  jar 里的三个解析器（聚合/并行/顺序）会直接出现在解析列表里。你之后填了自己的接口，这个默认配置就被你的接口取代，不影响你。
- **央视直播 ysp 脚本**：已放进包内 assets/ysp/。它仍是独立服务脚本（这一点变不了），
  用 Termux 跑手机里那份或用上次给你的文件都行；内置配置的直播里已预置"央视直播·ysp"指向 127.0.0.1:8767，服务起来就能看。
- **代理**：基座原生的配置级代理已在内置配置里预置好：github/google/youtube 等域名走 127.0.0.1:7890。
  前提是手机上有代理服务在 7890 端口跑着（任何 mihomo/Clash 类 APP 都行）；没跑代理时只有这些域名访问不了，国内片源不受影响。
  星落那种"APP 内订阅解析+内置内核"的代理形态仍无法移植（代码长在星落自己身上），这次给的是能真正落地的形态。
- **三引擎**：你的 OK 本来就有（jar/JS/PY），这次没动，内置 jar 就是靠它加载的。

## 出问题时

- 装不上：多半是旧版没卸干净，先卸载旧版再装。
- 打开后接口里没有"星落内置"：说明数据库里已有接口记录（比如恢复了备份），种子补丁只在接口为空时生效，属正常。
- 想还原：你的原版 merged-signed-v8.apk 我这里还存着，随时发你装回去（同样要先卸载，因为签名不同）。
